💡 문제가 생겼나요?

❌ "Git이 없다고 나옴"
→ https://git-scm.com/download/win 에서 다운로드 후 설치
→ 터미널 재시작

❌ "Node.js/npm이 없다고 나옴"
→ https://nodejs.org/ (LTS) 다운로드 후 설치
→ 터미널 재시작

❌ GitHub 로그인 안 됨
→ Personal Access Token 사용 (Settings → Developer settings → Tokens)

❌ Vercel 배포 실패
→ Vercel에 GitHub 계정으로 다시 로그인 시도
→ 리포지토리를 정상적으로 생성했는지 확인

✅ 대시보드 접속 확인
